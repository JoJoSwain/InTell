# M1 audio spike — build notes

## Windows setup
Clone/work from a short path like **`C:\dev\intell`**. Do **not** use `subst` drives (`R:` etc.) — they break the Android native build with a CMake “different roots” codegen error.

1. Enable Windows long paths (`LongPathsEnabled` = 1 under `HKLM:\SYSTEM\CurrentControlSet\Control\FileSystem`). See https://docs.expo.dev/troubleshooting/windows-long-paths/
2. Install Android SDK CMake **3.31.6** (includes Ninja 1.12.1) via SDK Manager.
3. Set in the **user-level** Gradle properties (`%USERPROFILE%\.gradle\gradle.properties`):
   ```
   android.cmakeVersion=3.31.6
   ```
   If Expo still invokes `cmake\3.22.1\bin\ninja.exe`, also add the same line to `apps/mobile/android/gradle.properties` (that file is regenerated by `prebuild --clean`, so re-add after a clean prebuild).
4. In the PowerShell session used for builds:
   ```powershell
   $env:ANDROID_HOME = "$env:LOCALAPPDATA\Android\Sdk"
   ```
   Confirm: `Test-Path "$env:ANDROID_HOME\platform-tools\adb.exe"` → `True`. Also set `JAVA_HOME` to Android Studio’s JBR if `java` is not on PATH (e.g. `C:\Program Files\Android\Android Studio\jbr`).

## Fixtures
```bash
pnpm --filter @intell/audio-fixtures generate
```
WAVs are gitignored. Run before Metro / prebuild / `run:android`.

## Android local dev build (required)
From `C:\dev\intell\apps\mobile` (PowerShell), after Windows setup above:

```powershell
$env:ANDROID_HOME = "$env:LOCALAPPDATA\Android\Sdk"
pnpm --filter @intell/audio-fixtures generate
pnpm exec expo prebuild --platform android --clean
# After clean prebuild, re-add android.cmakeVersion=3.31.6 to android\gradle.properties if needed
pnpm exec expo run:android
```

Deep link: `adb shell am start -a android.intent.action.VIEW -d "intell://dev/audio-spike"`

Package id: `org.replaceplace.intell`

## iOS cloud dev build (JoJo — needs credentials)
**Do not run credentialed EAS from the spike agent.**

1. Expo account + Apple Developer account; register the physical iPhone.
2. From `apps/mobile`:
   ```bash
   pnpm exec eas-cli init   # sets real projectId (app.json still has placeholder)
   pnpm exec eas-cli device:create
   pnpm exec eas-cli build --profile development --platform ios
   ```
3. `eas.json` `development` profile: `developmentClient: true`, `distribution: internal`, `ios.simulator: false`.
4. Install the build on device; open `intell://dev/audio-spike`.
